# 关于

这里是普通的 Markdown 页面，写什么都行。

## 怎么改

| 想改的 | 文件 |
| --- | --- |
| 站点名、导航、页脚、社交链接 | `.vitepress/config.ts` |
| 首页文案 | `index.md` |
| 作品 | `works/*.md`，一个作品一份 |
| 图片、二维码 | `public/` |

新增作品：复制 `works/` 里任意一份改改即可，`works/miaowa.md` 里有全部字段的注释。
